# Eubric AI Sales Roleplay Platform
# Development Journal

---

# Project Vision

Build a production-ready AI-powered Sales Roleplay Platform where sales representatives can practice realistic customer conversations with AI-generated buyer personas and receive instant coaching feedback.

The goal is to simulate real-world sales calls in a safe environment while helping users improve discovery, objection handling, communication, confidence, and closing skills.

## Challenges Faced

### Browser Speech Recognition

The browser Speech API occasionally misunderstood specific terms such as "Eubric AI". Transcript normalization and validation were introduced to improve recognition quality.

### Prompt Engineering

The greeting flow initially felt unnatural. Multiple iterations were required to achieve a realistic cold-call conversation.

### UI Design

Several dashboard layouts were explored before arriving at a cleaner, more professional SaaS interface.

### API Reliability

Temporary API quota limitations affected testing. The application was prepared to support alternative providers for demonstration purposes.

---

## Lessons Learned

- Prompt engineering is iterative.
- Small UX improvements significantly improve user perception.
- Voice AI requires preprocessing before sending transcripts.
- Conversation flow is just as important as model quality.
- Building production-ready software requires continuous refinement rather than one-time implementation.
